The method that can't lie

Floor plans are drawn as scripted SVG geometry, not generated as images. Walls, openings, and dimensions are computed — so a view can never contradict the plan it came from, and a dimension can't be wrong because a text-to-image model approximated it.

DeliverableHow it is produced
site mapComputed from plot size and orientation
dimensioned floor planScripted SVG geometry, dimension chain on the faces
3 viewsDerived from the same plan — never redrawn
3D previewDerived, so nothing contradicts the plan
denah_packageRecorded artifact, handed to the buyer on submit

Delivered as a denah_package artifact through iLands service submit — the buyer receives the package, not a screenshot.
